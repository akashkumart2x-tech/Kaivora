Agent SDK Docs

The Kaivora Agent SDK allows developers to initialize, configure, and orchestrate specialized autonomous AI Employees inside web applications and enterprise workflows. With built-in low-latency audio capture pipelines, turn-taking state machines, and real-time webhook updates, you can deploy a full-duplex sales assistant or customer support node in a few lines of code.

// Installation via npm npm install @kaivora/agent-sdk --save

Authentication & API Keys

All SDK calls must carry a secure Bearer token initialized in your developer control panel under standard settings coordinates. Keep these keys protected.

const { KaivoraClient } = require('@kaivora/agent-sdk'); // Initialize secure connection cluster const client = new KaivoraClient({ apiKey: 'kv_prod_live_88291aBcDeFgHiJkLmNoP', environment: 'production' });

Agent Creation

Deploy custom agents by referencing specialized playbooks, memory containment rules, and bi-directional CRM endpoints.

const agent = await client.agents.create({ name: 'Ava Support Pool', type: 'voice-receptionist', promptPlaybook: 'https://cdn.kaivora.ai/playbooks/inbound_sales.json', crmSync: { platform: 'hubspot', scopes: ['contacts.write', 'deals.write'] } }); console.log(`Agent Active: ${agent.id}`);

Voice Setup & WebRTC

Establish full-duplex, low-latency streaming speech synthesis by binding the microphone node to the active Kaivora voice audio channels.

// Bind real-time full-duplex audio pipeline const callStream = await client.voice.startSession({ agentId: agent.id, audioOptions: { sampleRate: 48000, echoCancellation: true, noiseSuppression: true } }); callStream.on('transcript', (data) => { console.log(`User: ${data.text}`); });

Webhook Configuration

Recieve secure endpoints updates in real-time when discovery meetings are booked or CRM client database variables get synchronized.

{ "event": "booking.completed", "timestamp": "2026-05-29T21:30:00Z", "data": { "agentId": "agent_voice_sec_01", "customer": { "name": "Sarah Miller", "email": "sarah@enterprise.com" }, "appointment": { "slot": "2026-06-02T14:00:00Z", "status": "confirmed" } } }

Error Reference Codes

Error Code Description Resolution
401_AUTH_FAILED API key is invalid or expired. Generate a new key inside dashboard.
429_LIMIT_EXCEEDED Rate limit of 60 requests/min hit. Implement backoff or upgrade your tier.
503_VOICE_TIMEOUT Audio pipeline connection timeout. Check local browser mic permission status.
