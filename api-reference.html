API Reference

Authentication Guide

Authenticate your API requests by including your secure Bearer key inside the standard authorization headers of your POST/GET request payloads.

Authorization: Bearer YOUR_API_KEY

POST Create Agent Instance

/v1/agents/create

Creates and provisions a new conversational chatbot or voice assistant instance using custom behavior rules and playbooks.

Body Parameters

  • name string (required) - The name of the digital employee.
  • type string (required) - either `voice-receptionist` or `chat-specialist`.
  • promptPlaybook string (required) - URL to JSON rules framework.

POST Dispatch Outbound Call

/v1/calls/dispatch

Triggers an autonomous outbound VoIP call connection using standard VAD structures and custom voice tuning.

Body Parameters

  • agentId string (required) - The ID of the configured voice agent.
  • phoneNumber string (required) - E.164 formatted number.

GET Get Telemetry

/v1/analytics/telemetry

Retrieves live conversational stats, sentiment analysis scores, and resolved ticket counts.

Request Example (POST)

{ "name": "Ava Support", "type": "voice-receptionist", "promptPlaybook": "https://cdn.kaivora.ai/rules.json" }

Response Example

{ "status": "success", "data": { "agentId": "agent_voice_sec_01", "created_at": "2026-05-29T21:30:00Z", "active": true } }
